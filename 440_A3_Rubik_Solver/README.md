# CSC 440 Assignment 3: Rubik Solver

A Python Rubik's Cube abstraction and solver that searches for short paths between cube positions. The `visualizer` folder contains the optional GUI and visualization helpers.

## Files

- `rubik.py`: Cube abstraction.
- `solver.py`: Solver implementation.
- `test_solver.py`: Unit tests.
- `visualizer/`: Visualization support.
